2. Pilih Approach Ekstraksi

Pilih satu atau lebih pendekatan untuk dijalankan. Approach lebih lambat (OCR / VLM) memerlukan waktu lebih lama dan—untuk VLM—biaya API.

⚠ Approach OCR butuh ~60 detik. Approach VLM butuh beberapa menit dan biaya API ($0,03–$0,50 per PDF). Estimasi waktu berdasarkan halaman 4–19 BBNI.

Hasil akan ditampilkan dalam format PSAK + raw JSON.

Skema Data Terpadu

Semua approach output JSON dengan struktur hierarkis yang sama (sections → nodes dengan level, label, values, children).

Ground Truth
